**Production data today:** 1 dealer, 0 franchise bookings / allocations, 0 commission ledger rows, 0 payouts; 99 zones, 349 areas, 2 franchise config versions. Migration risk is small.

**Main finding:** the system already has most building blocks (registration with online KYC, zone booking and payment, a team hierarchy, one ledger, monthly close, payouts, TDS, a generic approvals engine, versioned franchise config). What is missing is the *scheme* layer on top: today four commercial models are TypeScript code with rates spread over five stores. The plan adds schemes, versions and assignments, then turns the existing calculation paths into components of one calculator, without replacing the zone booking, ledger or payout code.
