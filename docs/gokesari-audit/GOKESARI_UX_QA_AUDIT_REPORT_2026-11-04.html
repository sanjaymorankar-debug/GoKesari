Environment and test-data notes (not app defects)

  • E-18 Rate limiter (HTTP 429) tripped during the run. The screen sweep and probes ran alongside the suite for ~20 minutes; the per-user limiter then answered 429 to the shop owner and customer. The 429 checks were re-run on their own afterwards (see Re-test).
  • E-19 Dealer pages are not on production yet. The suite's route list comes from the working tree, which has unreleased dealer pages; production answers 404 for them. Not a defect.
  • E-20 SC-GW precondition. The staging rider's Aadhaar is already VERIFIED from an earlier run, so the 'DigiLocker link issued (Pending)' step cannot happen. Test data, not an app defect.
  • E-21 Safari / WebKit could not run. Playwright's WebKit build does not load on this Mac's macOS 14.6 (missing _WKBrowserInspector). Safari and the iOS app need a manual pass on a real device.
  • E-22 Staging shop owner's active shop. The staging shop owner also owns 'QA Docs 2026-10-29 …' shops registered by earlier QA runs; Seller Central opens the newest one, so finance / inventory / order-list checks written for 'E2E Four Features Bakery' (TC-FIN-010, TC-SPI-008, TC-ORD-012, TC-DEL-020) read the wrong shop. Re-run with the shop chosen (gk_shop cookie) — see Re-test.
  • E-23 Staging rule afterPackingCancellation is on. With the rule on, a customer may cancel a packed (READY / ASSIGNED) order for a fee — by design (batch 2026-10 WS-C). TC-ORD-007 assumes the default (off). Not a defect; the check should read the rule.
  • E-24 Scheduled-delivery slot on the test shop. Checkout's Place order stays disabled until a delivery time is chosen for the test shop's scheduled delivery; TC-COD-002 / TC-PAY-007 do not pick a slot. Test update needed, app behaves as designed (the button says why).
  • E-25 Unreleased features in the test list. TC-SREF-006 (admin Shop referrals page) covers work that exists only in the local working tree, not on staging.
