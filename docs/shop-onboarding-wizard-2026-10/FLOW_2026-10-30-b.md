## The flow

```
/sell or /shop ─► one card "Register your shop" ─► /shop/register  (/shop/join forwards here)
  Sign in (code by email)
  1 Referral: Enter Referral Code | Request Referral Code  + documents to keep ready
  2 Shop email
  3 Do you have your documents now?   Yes ─────────────┐        No ──────────────┐
  4 Document window (Yes)  ◄─────────────────────────────┘                        │
      GSTIN  [Validate]   PAN [Validate]   Shop Act [Validate]                     │
      FSSAI (optional) [Validate]   Udyam (optional) [Validate]                    │
  5 Confirm details: retrieved shop name and owner name, address, turnover  ◄─────┘
  6 Review and pay
  7 Live (or waiting for an admin)
  8 Address and map location (after payment)
  9 Category  10 Products
```

The owner's brief numbered these "pages": page 2 = step 1 (referral options + documents list),
Yes / No = step 3, document window = step 4, page 3 = step 5 (confirm), page 4 = step 6 (payment),
page 5 = step 8 (address and location).

## Google Maps (fix 10)

Diagnosed in the browser on 30 Oct 2026, loading the site's own browser key on each site:

| Site | Key in the build | Google's answer |
|---|---|---|
| gokesari.com | yes | map and Places load, no error |
| test.gokesari.com | yes (a different key from production) | `RefererNotAllowedMapError` — "Your site URL to be authorized: https://test.gokesari.com/…" |

Not a code fault, the CSP or quota: the staging key's **website restrictions** don't list
`test.gokesari.com`. Fix (owner, Google Cloud Console → APIs & Services → Credentials → the browser key
used for staging → Website restrictions): add `https://test.gokesari.com/*`. The key itself stays in the
environment (`NEXT_PUBLIC_GOOGLE_MAPS_API_KEY`, build time), never in code.

Code change: Google loads its script even when it refuses the key and reports it only through
`window.gm_authFailure`, so the picker sat on a grey map. `lib/geo/provider.ts` now listens for it
(`onMapsAuthFailure`); the location picker then offers "Use my current location" and coordinates, and the
Nearby map switches to its drawn map.
